CHASE '76 — CK MY APPS
======================

Upload all files from this folder into the root of a new public GitHub repository.
GitHub repository > Settings > Pages > Deploy from a branch > main / (root) > Save.
The game then opens at https://YOUR_USERNAME.github.io/YOUR_REPOSITORY/

Open on iPad/iPhone in Safari, Share > Add to Home Screen to install the PWA.

GAME CONTROLS
-------------
Tap the numeric direction pad, swipe on the maze, or use arrow/number keys.
0 = random jump; 10 = stand still for the rest of the game; -1 = give up.
5 interceptors chase you. Lure them into high-voltage X fences or collisions.
A new maze is randomly generated; Replay Same Maze repeats the initial positions.

Settings includes Arcade Sound ON/OFF, contrast, Credits and CK My Apps link.
High scores / records and settings live in local browser storage.
Sound is generated with the Web Audio API; no copyrighted samples.
No backend, API, or paid services needed. Works offline after initial download.
